## Target after member contributions
Native sidebar navigation will list the dashboard and the five owner pages. Each page will receive the common population, then add its own controls and views. Every figure must show who, 2026, applied filters and the number answering that question. The individual pages are intentionally not designed or implemented here beyond this integration contract.

The common dashboard message is provisional until the five investigations have been discussed. The app is developed locally; public deployment is an optional final step.
